> 为了用户增长，大部分产品会通过一些手段提供免费额度（比如邀请、试用），黑产由此入手，不止算力可以被这样攻击

目前黑产榨取算力资源主要集中在四条核心路径：

1. 免费额度套利：通过自动化工具批量注册新账号，反复薅取平台的免费试用额度
2. 邀请积分套利：利用邀请奖励机制，循环注册、绑定邀请码、刷取积分
3. 高阶权益拆分超售：通过高阶账号拼车以及团队账户席位超售拆分权益，实现低价算力转售，造成平台资源被过度占用
4. API 逆向寄生套利：逆向 Web/API 接口，将网页端交互封装成廉价 API 对外出售
