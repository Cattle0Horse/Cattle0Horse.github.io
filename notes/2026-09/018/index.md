[这篇文章](https://mp.weixin.qq.com/s/ZSGtyU1IQjSlSAhkausETg) 读起来很难，很长但感觉信息密度很少，通过 AI 学习如何避免这类表达

| 表达问题                     | 可以使用的术语                 | 在文中的表现                                                             |
| ---------------------------- | ------------------------------ | ------------------------------------------------------------------------ |
| 核心主题不断变化             | **主题漂移、主线不稳**         | 从 AI 替代工作，转到英国学徒制，再转到中产阶层、工作伦理、阿伦特哲学     |
| 一个词反复改变含义           | **概念滑移、概念边界模糊**     | “中间层”一会儿指初级白领，一会儿指中层岗位，一会儿又接近社会中产阶层     |
| 用形象比喻代替解释           | **隐喻过载、意象堆叠**         | “传送带松动”“电梯停运”“三只钟错位”“三张座位表”“建立自己的头寸”           |
| 从材料直接跳到结论           | **论证跳跃、因果链缺失**       | 招聘下降、AI 工具普及，就被推导为职业阶梯正在坍塌                        |
| 事实、推测和观点混在一起     | **事实—判断—建议混杂**         | 数据、社会学理论、作者预测和个人建议没有明确区分                         |
| 句子很抽象                   | **抽象名词化、名词堆砌**       | “生存的供给端被机器接管”“时间的定价方式被改写”“身份失去锚点”             |
| 引用了很多理论家和数字       | **权威堆砌、引用装饰化**       | 提到苏斯金、贝克、格雷伯、阿伦特等，但没有充分解释他们各自如何支持主论点 |
| 同一观点反复换说法           | **修辞性重复、信息冗余**       | “中间层消失”“新人入口变窄”“职业阶梯坍塌”多次出现，实际新增信息有限       |
| 章节之间缺少明确承接         | **逻辑连接隐含、结构标记不足** | 每一节都像提出一个新观点，读者需要自己补出它们之间的关系                 |
| 语言有气势，但可验证内容有限 | **高概念叙事、宏大叙事**       | 经常从个别案例直接上升到“几代人的人生路径”“社会结构重组”                 |
